# The One-Liner Groan-Off

One original one-line dad joke for make.fun's "The One-Liner Groan-Off" bounty ($2 in USDC).

**Entry:** I told my Wi-Fi router a joke, but it didn't laugh — it just kept dropping the connection.

## Run

```sh
node main.ts
```
